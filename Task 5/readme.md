## 🧠 Problems and Solutions

### Problem 1: Social Media – Post Engagement Analyzer

**Description:**
Analyzes total likes on a post and determines whether the post is viral.

**Rules:**
- Total Likes ≥ 1000 → Viral Post
- Otherwise → Normal Engagement

**Concepts Used:**
- Function
- Loop
- Conditional logic

### Problem 2: Healthcare – Medicine Stock Alert System

**Description:**
Checks whether medicine stock is sufficient or needs restocking.

**Rules:**
- Stock < 10 → Low Stock Alert
- Stock ≥ 10 → Stock Sufficient

**Concepts Used:**
- Function
- Conditional statements

### Problem 10: Smart Electricity Bill Analyzer

**Description:**
Calculates electricity bill based on slab rates and classifies usage level.

**Billing Slabs:**
- First 100 units → ₹3 per unit
- Next 100 units → ₹5 per unit
- Above 200 units → ₹7 per unit

**Usage Classification:**
- Bill < ₹500 → Low Usage
- ₹500 – ₹1500 → Moderate Usage
- Bill > ₹1500 → High Usage

**Concepts Used:**
- Function
- Conditional logic
- Mathematical calculations
- Return values
